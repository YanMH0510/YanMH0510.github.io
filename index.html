PROFILE

关于我

我正在从玩家视角转向策划视角，用拆解与设计建立自己的策划方法。

我希望自己的作品集不是展示“我玩过什么”，而是展示“我如何理解一个游戏系统”。

我是颜墨涵，本科阶段学习计算机科学与技术，研究生阶段方向为教育技术学。

计算机背景让我更容易理解系统结构、规则逻辑与功能流程；教育技术背景让我关注用户学习路径、体验引导与反馈机制。

我正在从“玩家视角”转向“策划视角”：不只描述一个玩法是否有趣，而是尝试分析它为什么成立、服务什么目标、如何影响玩家行为，以及如何支撑长期运营。

01
战斗系统拆解
Combat Analysis

《绝区零》战斗系统拆解案

围绕《绝区零》的战斗系统进行拆解，分析其战斗核心特色、主界面信息布局、快速轮切机制、角色性能参数、技能体系、资源博弈、攻击规则与表现演出。

该文档重点关注战斗系统如何通过失衡值、异常值、支援点、能量、喧响值等资源构建策略选择；如何通过轮切、支援、QTE、极限闪避等机制形成多角色联动体验；以及如何通过镜头、音效、动画和受击反馈强化打击感。

角色系统反拆
System Reverse Analysis

《绝区零》角色系统反拆案

03
原创玩法策划
Gameplay Proposal

《绝区零》绳结域策划案

基于《绝区零》的“绳网”设定，设计一个偏家园 / 公会 / 社区协作方向的长期玩法系统“绳结域”。

方案目标是补足当前游戏中社区互动不足、资源获取方式较单一、玩法偏硬核的问题。系统通过绳结域创建与加入、成员职位、等级成长、科技发展、强敌讨伐、积分商店等功能，构建玩家之间的长期协作目标。

文档进一步细化了功能规则、开启条件、创建与加入流程、退出规则、升级流程、界面交互、按钮反馈和资源配置需求。
